# RPC Messenger

Терминальный мессенджер на C для двух процессов одного пользователя Linux.
Оба участника могут отправлять и получать сообщения одновременно.

## Сборка

Нужны компилятор C, `make`, `pkg-config` и заголовки GLib/GIO.

**Fedora**

```sh
sudo dnf install gcc make pkgconf-pkg-config glib2-devel
```

**Debian и Ubuntu**

```sh
sudo apt install build-essential pkg-config libglib2.0-dev
```

Из каталога репозитория выполните `make`. Появится бинарник `messenger`.

## Запуск

В первом терминале из каталога репозитория запустите:

```sh
./messenger listen
```

Во втором терминале откройте тот же каталог и скопируйте команду, которую напечатал первый. Путь к сеансу каждый раз новый. Пример команды для второго терминала:

```sh
./messenger connect /tmp/rpc-messenger-AbCd12
```

После сообщения «Связь установлена» наберите строку в любом терминале и нажмите Enter.
Ответ можно набрать сразу, пока собеседник вводит своё сообщение.
Команда `/quit` или Ctrl+D завершает сеанс. Для нового диалога снова запустите `listen`.

## Как работает RPC

Каждый процесс регистрирует один и тот же метод D-Bus `SendMessage` со строковым
аргументом и пустым ответом. При отправке GDBus вызывает этот метод у собеседника.
Обработчик печатает полученный текст и возвращает ответ. Чтение клавиатуры и RPC-вызовы
асинхронны, поэтому ожидание ввода или ответа не блокирует приём сообщений.

GDBus из GLib/GIO кодирует аргументы и сопоставляет запросы с ответами.
Прямое соединение использует два именованных канала, по одному на каждое направление.
Оба канала создаются в приватном временном каталоге. Когда процессы открывают каналы,
их имена удаляются, а открытые дескрипторы продолжают работать до конца сеанса.
Для запуска достаточно двух терминалов и одного бинарника.

## Исходники

- `main.c` разбирает аргументы и запускает сеанс.
- `transport.c` открывает два именованных канала и объединяет их в поток GIO.
- `chat.c` регистрирует RPC-метод и обрабатывает ввод и сообщения.

[Документация GDBus](https://docs.gtk.org/gio/class.DBusConnection.html)
